# Migration Calculator

migrate.fun LP recovery + launch calculator. Given a token or LP address it pulls live DEX pools and computes recoverable native liquidity (SOL/ETH/BNB), relaunch-cost tables, and a leftover-token breakdown. Solana, Ethereum, Base, BNB, Robinhood. No build step, no database, no secrets.

Scrubbed source snapshot (2026-10-20). Hosting remains on Emblem.
